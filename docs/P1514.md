# P1514 [NOIP 2010 提高组] 引水入城 题解

题目链接：<https://www.luogu.com.cn/problem/P1514>

## 一、题目大意

一个 `N × M`（`N, M <= 500`）的矩形，每座城市有海拔高度。

- 第一行毗邻**湖泊**，只能在这里建**蓄水厂**；
- 水借助高度差，从一座城市流向**相邻且海拔更低**的城市（上下左右均可，只要更低）；
- 第 N 行毗邻**沙漠**，要求其中每座城市都能被水浇到。

问：

1. **能否**让最后一行所有城市都有水？若不能，输出 `0` 和**不能建水利设施的城市数**；
2. 若能，输出 `1` 和**最少需要建几个蓄水厂**。

样例：

```text
2 5
9 1 5 4 3
8 7 6 1 2
```

输出 `1 / 1`（只在 `(1,1)` 建一个蓄水厂即可浇遍整行）。

## 二、解题思路

### 1. 拆成两个子问题

**第一问（可行性）**：从第一行每个格子出发做 BFS（水往更低的邻居流），标记所有能到达的格子。最后一行里没被标记的，就是"不能建水利设施"的城市，计数即可。

**第二问（最少蓄水厂）**：需要下面两个关键步骤。

### 2. 关键引理：每个蓄水厂的浇灌范围是一段连续区间

> **第一行某个格子能浇到的"最后一行城市"，一定是一段连续的列区间 `[L, R]`。**

这是本题的著名性质（由水流路径单调不交叉证明）。正因为连续，才能把问题转成"区间覆盖"。

### 3. 求每个第一行格子的区间（记忆化搜索）

对每个格子 `(x, y)`，记录它能到达的最后一行的**最左列 `L[x][y]` 和最右列 `R[x][y]`**：

- 若 `(x, y)` 在最后一行，则它本身是 `[y, y]`；
- 否则，它的区间 = 它所有"更低邻居"的区间的**并**（取 min 左端、max 右端）。

因为水只能往**更低**处流，依赖关系**无环**，可以记忆化搜索（每个格子只算一次）。

> 实现上为避免递归过深（最坏递减路径可能长达 `N×M = 25 万`，递归会爆栈），改用**按海拔升序处理所有格子**的迭代写法：升序处理时，"更低邻居"一定已经算过，直接合并即可，效果与记忆化 DFS 完全相同。

### 4. 贪心区间覆盖

得到第一行每个格子的区间后，问题变成经典的**用最少的区间覆盖 `[1, M]`**：

```text
按左端点排序 → 当前覆盖到 now，每次挑"左端点 ≤ now 的区间里右端点最远"的，贪心跳。
```

## 三、参考代码

```cpp
//
// 洛谷 P1514 引水入城
// 思路：多源 BFS 判断可行性 + 按高度升序求区间（记忆化迭代版）+ 贪心区间覆盖。
//

#include <iostream>
#include <algorithm>
#include <queue>
#include <vector>
#include <cstring>
#include <utility>
using namespace std;

const int INF = 1e9;
int N, M;
int h[505][505];
int L[505][505], R[505][505];
bool reach[505][505];
int dx[4] = {-1, 1, 0, 0};
int dy[4] = {0, 0, -1, 1};

struct Cell { int h, x, y; };

int main() {
    cin >> N >> M;
    for (int i = 1; i <= N; i++)
        for (int j = 1; j <= M; j++)
            cin >> h[i][j];

    // 第一问：多源 BFS
    queue<pair<int, int>> q;
    for (int j = 1; j <= M; j++) { reach[1][j] = true; q.push({1, j}); }
    while (!q.empty()) {
        int x = q.front().first, y = q.front().second; q.pop();
        for (int d = 0; d < 4; d++) {
            int nx = x + dx[d], ny = y + dy[d];
            if (nx < 1 || nx > N || ny < 1 || ny > M) continue;
            if (reach[nx][ny] || h[nx][ny] >= h[x][y]) continue;
            reach[nx][ny] = true;
            q.push({nx, ny});
        }
    }
    int un = 0;
    for (int j = 1; j <= M; j++) if (!reach[N][j]) un++;
    if (un > 0) { cout << 0 << endl << un << endl; return 0; }

    // 第二问：按高度升序求区间
    for (int i = 1; i <= N; i++)
        for (int j = 1; j <= M; j++)
            L[i][j] = INF, R[i][j] = 0;

    vector<Cell> cells;
    for (int i = 1; i <= N; i++)
        for (int j = 1; j <= M; j++)
            cells.push_back({h[i][j], i, j});
    sort(cells.begin(), cells.end(), [](const Cell& a, const Cell& b) { return a.h < b.h; });

    for (auto &c : cells) {
        int x = c.x, y = c.y;
        if (x == N) { L[x][y] = min(L[x][y], y); R[x][y] = max(R[x][y], y); }
        for (int d = 0; d < 4; d++) {
            int nx = x + dx[d], ny = y + dy[d];
            if (nx < 1 || nx > N || ny < 1 || ny > M) continue;
            if (h[nx][ny] >= h[x][y]) continue;
            L[x][y] = min(L[x][y], L[nx][ny]);
            R[x][y] = max(R[x][y], R[nx][ny]);
        }
    }

    vector<pair<int, int>> seg;
    for (int j = 1; j <= M; j++)
        if (L[1][j] <= R[1][j]) seg.push_back({L[1][j], R[1][j]});
    sort(seg.begin(), seg.end());

    int ans = 0, now = 1, idx = 0, sz = seg.size();
    while (now <= M) {
        int far = now - 1;
        while (idx < sz && seg[idx].first <= now) {
            far = max(far, seg[idx].second);
            idx++;
        }
        ans++;
        now = far + 1;
    }
    cout << 1 << endl << ans << endl;
    return 0;
}
```

## 四、复杂度分析

- **BFS**：`O(N·M)`；
- **区间计算**：排序 `O(N·M log(N·M))` + 每个格子常数次合并 `O(N·M)`；
- **贪心覆盖**：`O(M log M)`；
- 总复杂度 `O(N·M log(N·M))`，`N,M <= 500` 时约 25 万格子，轻松通过。

## 五、常见错误

1. **水只能往更低流，忘了"严格小于"**：用 `<=` 会形成等高环，导致死循环或错误。
2. **只往下流、不考虑向上/左右**：水可以向任意方向的更低格子流（样例里 `(1,1)` 就是先向下再向上绕到第 5 列），只写"向下"会 WA。
3. **递归 DFS 爆栈**：最长递减路径可达 25 万格，递归会栈溢出，建议用 BFS 或按高度升序的迭代写法。
4. **缺头文件导致 CE**：若用 `std::tuple` / `std::get` 却忘了 `#include <tuple>`，本地 clang 可能因间接包含而通过，但洛谷 GCC 会编译错误。建议显式 include，或用 `struct` 代替 `tuple`。
5. **没验证"区间连续"就直接贪心**：只有"存在解"时区间才连续；无解时要单独用 BFS 统计不可达城市数。
6. **贪心写错**：每次要选"左端点 ≤ 当前已覆盖位置、且右端点最远"的区间，而不是简单按右端点排序。

## 六、小结：搜索 + 贪心套路

| 步骤 | 方法 | 解决什么 |
|---|---|---|
| 第一问 | BFS（正向可达性） | 判断可行性、统计不可达数 |
| 关键引理 | 区间连续 | 把"浇灌范围"变成区间 |
| 第二问 | 记忆化搜索（求区间） | 每个第一行格子的 `[L,R]` |
| 最终 | 贪心区间覆盖 | 最少蓄水厂数 |

核心一句话：**先搜索求可达，再利用"连续区间"性质把问题转成经典贪心。**
