# P1019 [NOIP 2000 提高组] 单词接龙 题解

题目链接：<https://www.luogu.com.cn/problem/P1019>

## 一、题目大意

单词接龙是一个类似成语接龙的游戏。给定 `n` 个单词和一个起始字母，要求拼出一条以该字母开头的"龙"，使得龙的长度（字符总数）最大。

规则：

1. 龙的第一段必须以给定的起始字母开头；
2. 相邻两个单词相连时，前一个单词的**某个后缀**必须等于后一个单词的**某个前缀**，重合部分合并为一个（重合长度 `k >= 1`）；
3. 相邻两段不能存在包含关系，即重合长度 `k` 必须小于两个单词各自的长度（`k < len(A)` 且 `k < len(B)`）。例如 `at` 与 `atide` 不能相连，因为 `at` 整个是 `atide` 的前缀；
4. 每个单词最多在龙中出现 **2 次**。

输入格式：

- 第一行一个整数 `n`（`n <= 20`）表示单词个数；
- 接下来 `n` 行，每行一个单词；
- 最后一行一个字符，表示龙开头的字母（题目保证以该字母开头的龙一定存在）。

输出格式：一个整数，表示龙的最大长度。

样例输入：

```text
5
at
touch
cheat
choose
tact
a
```

样例输出：

```text
23
```

样例解释：一条最优龙为 `atactoucheatactouchoose`，即 `at + tact + touch + cheat + tact + touch + choose`。各单词长度之和为 `2+4+5+5+4+5+6 = 31`，各次重合长度为 `1+1+2+1+1+2 = 8`，故龙的长度为 `31 - 8 = 23`。

## 二、解题思路

### 1. 为什么用 DFS 回溯

龙是由单词一段一段拼出来的，拼接顺序就是搜索路径：

- 先选定以起始字母开头的第一个单词；
- 每次在龙尾尝试接上一个**没用满 2 次**、且能与当前龙尾合法重合的单词；
- 接不下去（或任意时刻）就停下来，更新答案；
- 换一种接法继续尝试，直到枚举完所有可能。

`n <= 20`、每个单词最多用 2 次，搜索空间很小，直接暴力 DFS + 回溯即可。

### 2. 预处理：overlap 矩阵

拼接是否合法只取决于**两个单词本身**，与龙前面的部分无关，所以可以提前对所有有序单词对 `(i, j)` 计算出重合长度：

```text
overlap[i][j] = 单词 i 接在单词 j 前面时的最短合法重合长度；-1 表示不可接
```

计算方法是枚举 `k` 从 `1` 到 `min(len_i, len_j) - 1`，判断：

```text
word[i] 的后 k 个字符 == word[j] 的前 k 个字符
```

第一个满足条件的 `k` 就是最短合法重合长度。

### 3. 为什么重合长度取最短

两个单词之间可能存在多个合法重合长度（例如 `ababa` 接 `ababa`，可以重合 1 个 `a`，也可以重合 3 个 `aba`）。

- 龙的总长度 = 所有单词长度之和 - 所有重合长度之和；
- 重合部分只影响**已经接好的部分**的长度，不影响龙的末尾，因此**不影响后续还能接什么单词**；
- 所以对每一对单词都取最短合法重合，龙的总长度一定最长。

### 4. 拼接后的长度如何计算

如果 `overlap[last][j] = k`，说明 `last` 接 `j` 时有 `k` 个字符重合：

```text
新长度 = 当前长度 + len(j) - k
```

### 5. 搜索细节

- 起点：枚举所有 `words[i][0] == start` 的单词作为龙的第一个单词，`used[i] = 1`，初始长度就是该单词的长度；
- 转移：枚举下一个单词 `j`，若 `used[j] < 2` 且 `overlap[last][j] != -1`，则递归；
- 回溯：递归返回后要恢复 `used[j]`；
- 答案：每次进入 DFS 时更新 `ans = max(ans, cur)`（龙可以在任意时刻停止）。

## 三、参考代码

```cpp
//
// 洛谷 P1019 单词接龙（NOIP 2000 提高组）
// 思路：预处理 overlap[i][j]（i 接 j 的最短合法重合长度） + DFS 回溯枚举拼接顺序。
//

#include <iostream>
#include <cstring>

using namespace std;

string words[25];    // 单词表，n <= 20，开 25 保险
int n, ans;          // n：单词个数；ans：龙的最大长度
int overlap[25][25]; // overlap[i][j]：单词 i 接在单词 j 前面的最短合法重合长度，-1 表示不可接
int used[25];        // used[i]：单词 i 在当前的龙中已被使用的次数（最多 2 次）

// 计算单词 i 接在单词 j 前面时的最短合法重合长度
int calc_overlap(int i, int j)
{
    int li = words[i].size(), lj = words[j].size();
    // 从 k=1 开始从小到大枚举，找到的第一个 k 就是最短合法重合
    for (int k = 1; k < min(li, lj); k++)
    {
        if (words[i].substr(li - k) == words[j].substr(0, k))
        {
            return k;   // 找到最短合法重合长度
        }
    }
    return -1;          // 没有任何合法重合，i 不能接在 j 前面
}

// DFS 回溯：当前龙的最后一个单词是 last，龙当前总长度为 cur
void dfs(int last, int cur)
{
    ans = max(ans, cur);    // 龙可以在任意时刻停下，随时更新答案

    // 枚举下一个要接的单词 j
    for (int j = 0; j < n; j++)
    {
        // 剪枝：单词 j 已用满 2 次，或 last 无法接到 j
        if (used[j] >= 2 || overlap[last][j] == -1) continue;

        used[j]++;          // 使用单词 j
        // 接上 j 后新增长度 = j 的长度 - 与 last 重合的部分
        dfs(j, cur + (int)words[j].size() - overlap[last][j]);
        used[j]--;          // 回溯：撤销标记
    }
}

int main()
{
    // ---------- 输入 ----------
    cin >> n;
    for (int i = 0; i < n; i++)
    {
        cin >> words[i];    // 读入 n 个单词
    }
    char start;
    cin >> start;           // 读入龙开头的字母

    // ---------- 预处理：计算所有有序单词对 (i, j) 的重合长度 ----------
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < n; j++)
        {
            overlap[i][j] = calc_overlap(i, j);
        }
    }

    // ---------- DFS：枚举龙的第一个单词 ----------
    for (int i = 0; i < n; i++)
    {
        if (words[i][0] == start)   // 第一个单词必须以起始字母开头
        {
            used[i] = 1;            // 第一个单词已使用 1 次
            dfs(i, words[i].size()); // 龙的初始长度就是该单词的长度
            used[i] = 0;            // 回溯，尝试其他起点
        }
    }

    cout << ans << endl;
    return 0;
}
```

## 四、复杂度分析

- **预处理**：枚举所有有序对 `(i, j)` 并逐个检查重合长度，时间复杂度 `O(n^2 * L)`，其中 `L` 是单词的最大长度（单词都很短，代价可忽略）；
- **DFS**：最坏情况下是指数级的，但 `n <= 20` 且每个单词最多使用 2 次，状态空间非常小，C++ 直接暴力回溯即可通过。

## 五、常见错误

1. **重合长度取最长而不是最短**。

   有的写法从 `k = min(len_i, len_j) - 1` 开始往下找第一个匹配，得到的是最长重合。这会让龙变短，导致答案错误。必须取**最短**合法重合。

2. **忘记防包含条件 `k < min(len_i, len_j)`**。

   如果允许 `k == len_i` 或 `k == len_j`，就会出现一个单词完全包含在另一个单词里的情况（如 `at` 与 `atide`），违反题意。

3. **漏掉自己接自己的情况（`i == j`）**。

   只要单词存在非空且非自身的"border"（如 `ababa` 可以接 `ababa`），自己接自己就是合法的，只是会消耗两次使用次数。预处理时不能跳过 `i == j`。

4. **`used` 数组忘记回溯**。

   DFS 进入递归前 `used[j]++`，返回后必须 `used[j]--`，否则一个分支的计数会污染其他分支。

5. **起点单词的计数处理错误**。

   龙以某个单词开头时，该单词已经使用了 1 次（`used[i] = 1`），而不是 0 次，否则它会被额外多用一次。
