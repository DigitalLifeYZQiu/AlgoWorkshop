# P1032 [NOIP 2002 提高组] 字串变换 题解

题目链接：<https://www.luogu.com.cn/problem/P1032>

## 一、题目大意

给定两个字符串 `A`、`B`，以及**最多 6 条**变换规则 `Ai -> Bi`（字符串长度 ≤ 20）。规则含义：当前字符串中的任意一个子串 `Ai` 可以替换成 `Bi`。

求把 `A` 经过若干次变换变成 `B` 的**最少步数**；若 **10 步（含）以内**无法完成，输出 `NO ANSWER!`。

输入格式（规则读到文件结束为止）：

```text
A B
A1 B1
A2 B2
...
```

样例：

```text
abcd xyz
abc xu
ud y
y yz
```

变换过程：`abcd → xud → xy → xyz`，共 3 步，输出 `3`。

## 二、解题思路

### 1. 为什么用 BFS

这仍是一道**无权图最短路**，只是"图"不再是网格，而是**字符串状态图**：

- **状态（节点）**：一个字符串；
- **边（一步变换）**：对某条规则，在字符串某个位置做一次替换；
- 每条边权都是 `1`（一次变换），求最少步数 = 求无权最短路 → **BFS**。

### 2. 转移怎么写

对当前字符串 `s`，枚举每条规则 `(from, to)`，再枚举 `from` 在 `s` 中出现的**每个位置**，做一次替换得到新字符串：

```cpp
size_t pos = 0;
while ((pos = s.find(from, pos)) != string::npos) {
    string t = s;
    t.replace(pos, from.size(), to);   // 在 pos 处把 from 换成 to
    // 把 t 作为新状态入队
    pos++;                             // 前进一步，找下一个（含重叠）出现位置
}
```

> 注意 `pos++` 而不是 `pos += from.size()`：为了找到**重叠**的出现位置。比如 `from = "aa"`、`s = "aaa"`，两个出现位置分别是 0 和 1，用 `pos++` 才能都找到。

**必须用 visited 去重**：规则可能造成环（如 `ab->ba` 和 `ba->ab`），不去重会无限循环；同一个字符串第一次到达时步数一定最小，之后不用再访问。

### 3. 步数限制与 "NO ANSWER!"

BFS 按层扩展，当弹出的字符串已经 `d >= 10` 步，就不再继续变换（下一步就超过 10 步了）。队列清空还没找到 `B`，说明 10 步内不可达，输出 `NO ANSWER!`。

## 三、参考代码

```cpp
//
// 洛谷 P1032 字串变换
// 思路：状态 = 字符串，BFS 求最少变换步数，map 去重。
//

#include <iostream>
#include <queue>
#include <map>
#include <string>
using namespace std;

string A, B;
string from[7], to[7];
int cnt = 0;

int bfs()
{
    queue<pair<string, int>> q;
    map<string, int> step;

    q.push({A, 0});
    step[A] = 0;

    while (!q.empty())
    {
        string s = q.front().first;
        int d = q.front().second;
        q.pop();

        if (s == B) return d;
        if (d >= 10) continue;

        for (int i = 0; i < cnt; i++)
        {
            size_t pos = 0;
            while ((pos = s.find(from[i], pos)) != string::npos)
            {
                string t = s;
                t.replace(pos, from[i].size(), to[i]);
                if (!step.count(t))
                {
                    step[t] = d + 1;
                    q.push({t, d + 1});
                }
                pos++;
            }
        }
    }
    return -1;
}

int main()
{
    cin >> A >> B;
    string a, b;
    while (cin >> a >> b)
    {
        from[cnt] = a;
        to[cnt] = b;
        cnt++;
    }

    int ans = bfs();
    if (ans == -1) cout << "NO ANSWER!" << endl;
    else cout << ans << endl;
    return 0;
}
```

## 四、复杂度与优化

- **朴素 BFS**：状态是字符串，数量取决于数据，理论上可能较多，但本题数据下朴素 BFS + 去重即可通过；
- **双向 BFS（优化）**：同时从 `A` 正向搜、从 `B` 反向搜（反向用每条规则 `Bi -> Ai`），两边相遇时步数相加。能把搜索空间从 `O(b^10)` 降到约 `O(b^5)`，数据较大时更稳。

## 五、常见错误

1. **不设步数上限**：题目要求 10 步内，超过要输出 `NO ANSWER!`，不能一直搜。
2. **忘记 visited 去重**：规则环会导致死循环（如 `ab->ba`、`ba->ab`）。
3. **`pos` 没 `++`**：死循环在同一个位置；或用了 `pos += from.size()` 漏掉重叠出现。
4. **读规则方式错**：规则数不显式给出，要 `while (cin >> a >> b)` 读到 EOF。
5. **字符串可能变长**：`to` 可以比 `from` 长，状态串长度会增长，用 `string` 动态存储即可。

## 六、小结：搜索的又一种"状态"

| 之前 | 本题 P1032 |
|---|---|
| 状态 = 坐标 `(x,y)` | 状态 = **字符串** |
| 邻居 = 上下左右 | 邻居 = 每条规则 × 每个位置替换 |
| BFS 求网格最短路 | BFS 求**字符串变换最少步数** |

核心：**BFS 的"状态"可以是任何东西（坐标、字符串、棋盘局面…），只要你能枚举出"一步能变成哪些邻居"。**
