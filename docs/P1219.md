# P1219 [USACO1.5] 八皇后 Checker Challenge 题解

题目链接：<https://www.luogu.com.cn/problem/P1219>

## 一、题目大意

在一个 `n x n` 的棋盘上放置 `n` 个棋子，要求：

1. 每行恰好有一个棋子；
2. 每列恰好有一个棋子；
3. 每条斜线（左上到右下、右上到左下两个方向）上至多有一个棋子。

一个解用一个序列表示：第 `i` 个数字表示第 `i` 行的棋子所在的列号。

题目要求：

- 按字典序输出前 3 个解；
- 最后输出解的总数。

输入格式：一行一个正整数 `n`。

输出格式：前三行各输出一个解，数字之间用空格隔开；第四行输出解的总数。

数据范围：`6 <= n <= 13`。

样例输入：

```text
6
```

样例输出：

```text
2 4 6 1 3 5
3 6 2 5 1 4
4 1 5 2 6 3
4
```

## 二、解题思路

### 1. 为什么用回溯

因为每一行必须且只能放一个棋子，所以可以一行一行地处理：

- 当前处理第 `r` 行；
- 尝试把棋子放在第 `c` 列；
- 如果 `(r, c)` 不会被前面已经放好的棋子攻击，就放上去；
- 继续递归处理第 `r + 1` 行；
- 如果某一步走不通，就撤销当前选择，尝试下一列。

这就是典型的深度优先搜索 + 回溯。

### 2. 如何快速判断冲突

设当前考虑第 `r` 行、第 `c` 列。

列冲突很好判断：

```text
col[c] 为 true 表示第 c 列已经被占用
```

两条斜线可以通过行列坐标的和与差来判断：

- 同一条左上到右下的斜线上，所有格子的 `r - c` 相同；
- 同一条右上到左下的斜线上，所有格子的 `r + c` 相同。

因此可以用两个数组分别标记：

```text
d1[r - c + n]
d2[r + c]
```

其中 `r - c + n` 是为了把可能的负数下标变成非负数。

### 3. 字典序

在每一行中，列号都从 `1` 到 `n` 依次尝试，这样：

- 第 1 行优先选择最小的合法列；
- 第 2 行再优先选择最小的合法列；
- 以此类推。

所以搜索得到的解天然就是字典序排列的，不需要额外排序。

## 三、参考代码

### 数组标记版

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, cnt;
int ans[20];
bool col[20], d1[40], d2[40];

void dfs(int r) {
    if (r > n) {
        cnt++;
        if (cnt <= 3) {
            for (int i = 1; i <= n; i++) {
                cout << ans[i] << (i == n ? '\n' : ' ');
            }
        }
        return;
    }

    for (int c = 1; c <= n; c++) {
        if (col[c] || d1[r - c + n] || d2[r + c]) continue;

        ans[r] = c;
        col[c] = d1[r - c + n] = d2[r + c] = true;

        dfs(r + 1);

        col[c] = d1[r - c + n] = d2[r + c] = false;
    }
}

int main() {
    cin >> n;
    dfs(1);
    cout << cnt << endl;
    return 0;
}
```

### 位运算优化版

当 `n` 接近 13 时，数组版也可以通过；如果希望进一步优化，可以用位运算标记列和斜线。

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, cnt;
int ans[20];

void dfs(int r, int col, int d1, int d2) {
    if (r > n) {
        cnt++;
        if (cnt <= 3) {
            for (int i = 1; i <= n; i++) {
                cout << ans[i] << (i == n ? '\n' : ' ');
            }
        }
        return;
    }

    int full = (1 << n) - 1;
    int avail = full & ~(col | d1 | d2);

    while (avail) {
        int p = avail & -avail;          // 取出最低位的 1
        int c = __builtin_ctz(p) + 1;    // 转换为列号，1-based
        ans[r] = c;

        dfs(r + 1,
            col | p,
            (d1 | p) << 1,
            (d2 | p) >> 1);

        avail ^= p;                       // 去掉已经尝试过的位置
    }
}

int main() {
    cin >> n;
    dfs(1, 0, 0, 0);
    cout << cnt << endl;
    return 0;
}
```

## 四、复杂度分析

理论上 N 皇后问题的搜索空间上界是 `O(n!)`。

本题因为有列冲突和斜线冲突的剪枝，实际访问量远小于上界。对于 `n = 13`，总解数为 `73712`，使用数组版 DFS 在 C++ 中通常可以通过。

## 五、常见错误

1. 输出时误用 `ans[0]`。

解是从 `ans[1]` 开始存储的，`ans[0]` 没有初始化，直接输出会产生随机值。

2. 输出循环写错范围。

应该输出 `ans[1]` 到 `ans[n]`，而不是输出 `cnt` 个元素。

3. 换行条件写错。

应该在 `i == n` 时输出换行。如果循环写成 `i < n`，则永远无法输出换行，导致三个解连在一起。

4. 对角线数组大小不足。

`r - c + n` 的范围大约是 `1` 到 `2n - 1`，`r + c` 的范围大约是 `2` 到 `2n`，数组开到 `40` 足够本题使用。
