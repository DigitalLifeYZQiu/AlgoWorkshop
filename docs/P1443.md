# P1443 马的遍历 题解

题目链接：<https://www.luogu.com.cn/problem/P1443>

## 一、题目大意

一个 `n × m` 的棋盘（`n, m <= 400`），有一匹马站在起点 `(x, y)`。马按"日"字形走 8 个方向。求从起点**最少走几步**能到达棋盘上的每个格子。

输出一个 `n × m` 的矩阵：每个格子填最少步数，**到不了的填 `-1`**。每个数字**占 5 个字符宽度、左对齐**。

样例输入：

```text
3 3 1 1
```

样例输出：

```text
0    3    2
3    -1   1
2    1    4
```

（`(2,2)` 是棋盘中心，马无论怎么跳都到不了，所以是 `-1`。）

## 二、解题思路

### 1. 为什么用 BFS

马每走一步距离 +1，这是典型的**无权图最短路**。BFS 的队列天然保证**按距离分层**：距离 0 → 1 → 2 → …。因此：

> 某个格子**第一次被 BFS 访问到**时，记录下的步数就是它的最短路；已经访问过的格子直接跳过。

DFS 一路深搜到底，不能保证第一次到达是最短，所以这里必须用 BFS。

### 2. 马的 8 个方向

"日"字形走法，本质是 8 个偏移（一个方向 ±1，另一个方向 ±2）：

```text
dx[8] = {-2,-1, 1, 2, 2, 1,-1,-2}
dy[8] = { 1, 2, 2, 1,-1,-2,-2,-1}
```

### 3. BFS 过程

```text
起点入队，dist[起点] = 0
while 队列不空:
    取出队首 (cx, cy)
    枚举 8 个方向 → 邻居 (nx, ny)
        若越界 → 跳过
        若 dist[nx][ny] != -1（已访问）→ 跳过
        否则：dist[nx][ny] = dist[cx][cy] + 1，入队
```

`dist` 数组同时充当"是否访问过"和"答案"两个角色：初始化为 `-1` 表示未访问/不可达。

## 三、参考代码

```cpp
//
// 洛谷 P1443 马的遍历
// 思路：BFS 按层扩散求无权图最短路。
//

#include <iostream>
#include <queue>
#include <iomanip>
using namespace std;

int n, m;
int dist[405][405];
int dx[8] = {-2, -1, 1, 2, 2, 1, -1, -2};
int dy[8] = {1, 2, 2, 1, -1, -2, -2, -1};

void bfs(int sx, int sy)
{
    queue<pair<int, int>> q;
    q.push({sx, sy});
    dist[sx][sy] = 0;
    while (!q.empty())
    {
        int cx = q.front().first, cy = q.front().second;
        q.pop();
        for (int d = 0; d < 8; d++)
        {
            int nx = cx + dx[d], ny = cy + dy[d];
            if (nx < 1 || nx > n || ny < 1 || ny > m) continue;  // 越界
            if (dist[nx][ny] != -1) continue;                    // 已访问
            dist[nx][ny] = dist[cx][cy] + 1;
            q.push({nx, ny});
        }
    }
}

int main()
{
    int sx, sy;
    cin >> n >> m >> sx >> sy;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            dist[i][j] = -1;

    bfs(sx, sy);

    cout << left;
    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= m; j++)
            cout << setw(5) << dist[i][j];   // 每个数占 5 宽、左对齐
        cout << '\n';
    }
    return 0;
}
```

## 四、复杂度分析

- **时间**：每个格子最多入队一次，每次枚举 8 个方向，`O(n·m·8) = O(n·m)`，`400×400 = 16 万`，瞬间完成；
- **空间**：`O(n·m)`（`dist` + 队列）。

## 五、常见错误

1. **输出格式**：每个数要占 5 字符宽度、左对齐，可用 `printf("%-5d", x)` 或 `cout << setw(5) << left << x`。用 `cout << x << " "` 只隔一个空格，格式不符，可能被判错。
2. **坐标从 1 开始**：题目给的是 1-based 坐标，越界判断是 `nx < 1 || nx > n`，不是 `nx < 0`。
3. **漏掉某几个方向**：马有 8 个方向，少写一个会导致答案错误。
4. **用 `dist == 0` 判断是否访问过**：起点本身就是 0，会出 bug。要用 `-1` 表示"未访问"，起点显式设为 0。
5. **用 DFS 做**：DFS 不能保证第一次到达是最短，会得到错误的步数。

## 六、小结

| | P1162 填涂颜色 | P1443 马的遍历 |
|---|---|---|
| BFS 用途 | 洪水填充（标记连通区域） | **无权图最短路（按层扩散）** |
| 关键性质 | 能到达 = 连通 | 第一次到达 = 最短路 |
| 标记 | `vis`（布尔） | `dist`（记录距离，`-1` 表示未访问） |
