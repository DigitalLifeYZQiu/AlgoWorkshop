# P1378 油滴扩展 题解

题目链接：<https://www.luogu.com.cn/problem/P1378>

## 一、题目大意

有一个**长方形盒子**，用它的两个对角顶点给出（坐标范围为 `[-1000, 1000]`，含负数）。盒内有 `N` 个相异的点（`0 <= N <= 6`）。

在某个点上放一个小油滴，它会**一直扩展成一个圆**，直到碰到：

1. 盒子的边界；或
2. 其他已经放好的油滴（圆之间不能重叠）。

必须等一个油滴扩展完毕才能放下一个。求按什么顺序放这 `N` 个油滴，才能让**油滴覆盖的总面积最大**。

输出的是**剩余面积**（盒子面积 − 最大覆盖面积），结果**四舍五入**取整数。

输入格式：

- 第一行一个整数 `N`；
- 第二行四个整数 `x1 y1 x2 y2`，为矩形一个顶点及其对角顶点坐标；
- 接下来 `N` 行，每行两个整数 `xi yi`，为盒内点的坐标。

输出格式：一行一个整数，长方形盒子剩余的最小空间（四舍五入）。

样例输入：

```text
2
20 0 10 10
13 3
17 7
```

样例输出：

```text
50
```

样例解释：盒子为 `10 × 10 = 100`。先放 `(13,3)` 半径 3，再放 `(17,7)` 时受 `(13,3)` 限制，半径为约 2.66，覆盖约 50.45，剩余 49.55，四舍五入得 50。

## 二、解题思路

### 1. 排列型搜索

`N <= 6`，放置顺序不同结果就不同，所有顺序共 `6! = 720` 种，直接枚举。这是典型的**排列型搜索**，与全排列、八皇后同一套模板：

| 四问 | P1378 的答案 |
|---|---|
| ① 状态 | `used[]`（哪些油滴已放）+ `r[]`（已放油滴的半径）+ `sum`（当前覆盖面积） |
| ② 选择 | 下一个放哪个**还没放**的油滴 |
| ③ 答案 | 放完所有油滴后的总覆盖面积（取最大） |
| ④ 剪枝 | 无（`N` 太小，无需剪枝） |

### 2. 核心：半径的模拟计算

搜索本身简单，难点是确定**当前油滴能扩展到多大**。设当前放第 `i` 个油滴：

```text
r_i = min( 到四条边的距离,  到每个已放油滴 j 的距离 − r_j )
```

- **到边界**：`min(|x_i − X1|, |x_i − X2|, |y_i − Y1|, |y_i − Y2|)`。对两个对角顶点都取绝对值再取 min，天然覆盖上下左右四堵墙，无需纠结哪个角是左上。
- **到已放油滴**：圆 i 不能与圆 j 重叠，所以 `r_i <= 圆心距 − r_j`。
- 若圆心 i 已经落在某个已放圆内（`圆心距 < r_j`），半径就是 `0`（用 `max(0, ...)` 兜底）。

### 3. 搜索过程

对每个没放的油滴：算半径 → 标记 → 递归 → 撤销，枚举完所有顺序取最大覆盖面积，最后 `剩余面积 = 盒子面积 − 最大覆盖面积`。

## 三、参考代码

```cpp
//
// 洛谷 P1378 油滴扩展
// 思路：DFS 枚举放置顺序（排列型搜索）+ 每次放置时模拟计算最大半径。
//

#include <iostream>
#include <cmath>
#include <algorithm>

using namespace std;

const double PI = acos(-1.0);   // 精确的 π

int n;
double X1, Y1, X2, Y2;          // 矩形两个对角顶点
double x[7], y[7];              // 油滴坐标（N <= 6）
double r[7];                    // 已放油滴的半径
bool used[7];                   // 该油滴是否已经放置
double ans;                     // 覆盖的最大面积

double calcR(int i)
{
    // 到矩形四条边的距离
    double res = min({fabs(x[i] - X1), fabs(x[i] - X2),
                      fabs(y[i] - Y1), fabs(y[i] - Y2)});
    // 到每个已放油滴的约束：圆之间不能重叠
    for (int j = 0; j < n; j++)
    {
        if (!used[j]) continue;
        double d = hypot(x[i] - x[j], y[i] - y[j]);   // 两圆心距离
        res = min(res, d - r[j]);
    }
    return max(0.0, res);        // 若圆心已被覆盖，半径为 0
}

void dfs(int cnt, double sum)
{
    ans = max(ans, sum);
    for (int i = 0; i < n; i++)
    {
        if (used[i]) continue;
        r[i] = calcR(i);         // 做选择
        used[i] = true;
        dfs(cnt + 1, sum + PI * r[i] * r[i]);
        used[i] = false;         // 回溯
    }
}

int main()
{
    cin >> n;
    cin >> X1 >> Y1 >> X2 >> Y2;
    for (int i = 0; i < n; i++)
        cin >> x[i] >> y[i];

    dfs(0, 0);

    double boxArea = fabs(X1 - X2) * fabs(Y1 - Y2);   // 盒子面积
    cout << (int)(boxArea - ans + 0.5) << endl;       // 剩余面积，四舍五入
    return 0;
}
```

## 四、复杂度分析

- **搜索**：全排列，`O(N!)`，`N <= 6` 时仅 720；
- **每次半径计算**：`O(N)`（扫一遍已放油滴），总 `O(N! · N)`；
- **空间**：`O(N)`。

## 五、常见错误

1. **忘了处理坐标顺序/负数**：两个对角顶点可能"先右下后左上"，直接用 `fabs` 取 min，不要假设 `x1 < x2` 或 `y1 < y2`。
2. **半径没取 `max(0, ...)`**：当某个点被前面的圆完全盖住时，`d − r[j]` 是负数，必须夹成 0，否则面积会算错。
3. **π 精度太低**：写 `3.1415926` 在四舍五入边界可能差 1，用 `acos(-1.0)` 最稳。
4. **四舍五入方式**：`(int)(x + 0.5)` 只适用于非负数；剩余面积 ≥ 0，可以直接用。
5. **`r[i]` 回溯是否需要清空**：不需要。每次放置 `i` 都会重新 `calcR(i)` 覆盖，且 `calcR` 只读 `used[j]==true` 的油滴，回溯后该油滴不再被读取。
