# P3956 [NOIP2017 普及组] 棋盘 题解

题目链接：<https://www.luogu.com.cn/problem/P3956>

## 一、题目大意

一个 `m × m` 的棋盘（`m <= 100`），每个格子要么**红**（`0`）、**黄**（`1`），要么**无色**。要从左上角 `(1,1)` 走到右下角 `(m,m)`，求最少金币数。

规则：

1. **只能站在有颜色的格子上**（无色格子不能直接落脚）；
2. **移动**：走到相邻的有色格子，颜色相同花 `0` 金币，不同花 `1` 金币；
3. **魔法**：花 `2` 金币，让相邻的无色格子暂时变成你指定的颜色，然后走上去；**但魔法不能连续用**——刚用魔法变出来的格子，下一步必须走到"本来就有颜色"的格子上；
4. 左上角 `(1,1)` 保证有颜色；到不了就输出 `-1`。

输入格式：

- 第一行两个整数 `m n`，分别为棋盘大小、有色格子数量；
- 接下来 `n` 行，每行三个整数 `x y c`，表示格子 `(x,y)` 的颜色为 `c`（`0` 红 `1` 黄）。

输出格式：一行一个整数，最少金币数；无法到达输出 `-1`。

样例1：

```text
5 7
1 1 0
1 2 0
2 2 1
3 3 1
3 4 0
4 4 1
5 5 0
```

输出 `8`。

样例2：

```text
5 5
1 1 0
1 2 0
2 2 1
3 3 1
5 5 0
```

输出 `-1`。

## 二、解题思路

### 1. 关键难点：状态要记住"能否用魔法"

普通 BFS 求最短路，状态是 `(x, y)`。但这题不够，因为"魔法不能连续用"这条规则取决于**当前格子是不是刚用魔法变出来的**。所以状态必须多带一个信息 `used`：

| `used` | 含义 | 下一步能否用魔法 |
|---|---|---|
| `0` | 当前是**真实有色**格子 | ✅ 可以 |
| `1` | 当前是**魔法临时**格子 | ❌ 不可以 |

再带上当前格子的**颜色** `color`（魔法格的颜色是你指定的），状态就是 `(x, y, color, used)`。

### 2. 建模成带权最短路（边权 0/1/2）

从状态 `(x, y, color, used)` 走向邻居 `(nx, ny)`：

**（1）邻居是真实有色格子**（颜色 `c2`）：

```text
花费 = (c2 == color ? 0 : 1)
新状态 = (nx, ny, c2, used=0)     // 到了真实格，魔法恢复可用
```

**（2）邻居是无色格子**：

```text
必须 used == 0 才能用魔法（否则跳过）
花费 = 2                          // 魔法固定花 2
新状态 = (nx, ny, color, used=1)  // 魔法格继承当前颜色，魔法不可用
```

> **为什么魔法格继承当前颜色？** 用魔法时颜色由你指定，指定成和当前格子相同，这一步就只花 2（不多花异色的 1）。可以证明：无论魔法格指定成什么颜色，`有色→魔法→有色` 这段的总花费都是 `2 + (前色≠后色)`，与指定色无关，所以"指定成当前色"一定最优。

### 3. 为什么用 Dijkstra 而不是普通 BFS

边权是 `0/1/2` 不是统一的 `1`，普通 BFS（按步数分层）无法保证"第一次到达 = 最短路"。所以用**优先队列的 Dijkstra**（每次弹出花费最小的状态）。

## 三、参考代码

```cpp
//
// 洛谷 P3956 棋盘
// 思路：状态带"是否刚用过魔法"，Dijkstra 求带权最短路（边权 0/1/2）。
//

#include <iostream>
#include <queue>
#include <cstring>
using namespace std;

const int INF = 0x3f3f3f3f;

int m, n;
int grid[105][105];            // -1 无色，0 红，1 黄
int dist[105][105][2][2];      // dist[x][y][color][used]
int dx[4] = {-1, 1, 0, 0};
int dy[4] = {0, 0, -1, 1};

struct State
{
    int x, y, color, used, cost;
    bool operator<(const State& o) const { return cost > o.cost; }
};

int dijkstra()
{
    memset(dist, 0x3f, sizeof(dist));
    priority_queue<State> pq;

    dist[1][1][grid[1][1]][0] = 0;
    pq.push({1, 1, grid[1][1], 0, 0});

    while (!pq.empty())
    {
        State s = pq.top();
        pq.pop();
        if (s.cost > dist[s.x][s.y][s.color][s.used]) continue;

        for (int d = 0; d < 4; d++)
        {
            int nx = s.x + dx[d], ny = s.y + dy[d];
            if (nx < 1 || nx > m || ny < 1 || ny > m) continue;

            if (grid[nx][ny] != -1)
            {
                int c2 = grid[nx][ny];
                int nc = s.cost + (c2 == s.color ? 0 : 1);
                if (nc < dist[nx][ny][c2][0])
                {
                    dist[nx][ny][c2][0] = nc;
                    pq.push({nx, ny, c2, 0, nc});
                }
            }
            else
            {
                if (s.used == 1) continue;
                int nc = s.cost + 2;
                if (nc < dist[nx][ny][s.color][1])
                {
                    dist[nx][ny][s.color][1] = nc;
                    pq.push({nx, ny, s.color, 1, nc});
                }
            }
        }
    }

    int ans = INF;
    for (int c = 0; c < 2; c++)
        for (int u = 0; u < 2; u++)
            ans = min(ans, dist[m][m][c][u]);
    return ans == INF ? -1 : ans;
}

int main()
{
    cin >> m >> n;
    memset(grid, -1, sizeof(grid));
    for (int i = 0; i < n; i++)
    {
        int x, y, c;
        cin >> x >> y >> c;
        grid[x][y] = c;
    }
    cout << dijkstra() << endl;
    return 0;
}
```

## 四、复杂度分析

- 状态数：`m × m × 2 × 2 = 40000`；
- Dijkstra：`O(状态数 × 4 × log)`，`m <= 100` 时瞬间完成；
- 空间：`O(m²)`。

## 五、常见错误

1. **状态没带 `used`**：只记 `(x, y)`，会违反"不能连续用魔法"，多算或少算。
2. **用普通 BFS 而不是 Dijkstra**：边权有 0/1/2，普通 BFS 会得到错误的最短路。
3. **魔法格颜色处理错**：忘记魔法格颜色 = 指定颜色（继承当前色），导致下一步异色判断错误。
4. **终点可能是无色格子**：`(m,m)` 若无色，需要靠魔法到达，答案要在 `used` 两个状态里都取 min。
5. **忘记判 `-1`**：`(m,m)` 所有状态都不可达时输出 `-1`。

## 六、小结：从 P1443 到 P3956 的进阶

| | P1443 马的遍历 | P3956 棋盘 |
|---|---|---|
| 边权 | 全为 1 | **0 / 1 / 2** |
| 算法 | 普通 BFS | **Dijkstra（优先队列）** |
| 状态 | `(x, y)` | `(x, y, color, used)`（带额外规则状态） |
| 难点 | 最短路本身 | **"魔法不能连续用" → 状态维度扩展** |

核心一句话：**当题目有"额外规则"（如不能连续用魔法）时，把规则编码进搜索状态即可。**

## 七、Dijkstra 类题目的通用解法

### 1. 什么时候想到 Dijkstra

- 求"最小代价 / 最短路"，且**每一步的代价是非负整数但不全是 1**（如 0/1/2、不同边权）；
- 若边权**全为 1** → 普通 BFS 即可（如 P1443、P1162）；
- 若边权**只有 0 和 1** → 可用「0-1 BFS」（双端队列）优化，但 Dijkstra 也一定能过。

### 2. 通用解题四步

1. **定义状态**：把题目里所有"会影响后续决策"的因素都编码进状态（如本题的 `color`、`used`）。这是最关键的一步。
2. **建模边权**：从状态 S 转移到状态 S' 的花费是多少（本题是 0/1/2）。
3. **跑 Dijkstra**：优先队列 + `dist[状态]` 记录最小花费；弹出状态时若不是当前最优就跳过（过期节点）。
4. **取答案**：终点可能对应多个状态（如 `used=0/1`），全部取 min；都不可达输出 `-1`。

### 3. 通用代码模板

```cpp
struct State {
    // ... 状态字段（坐标、颜色、标记等）...
    int cost;
    bool operator<(const State& o) const { return cost > o.cost; }  // 小根堆
};

int dijkstra() {
    memset(dist, 0x3f, sizeof(dist));   // 所有状态初始化为无穷大
    priority_queue<State> pq;
    dist[起始状态] = 0;
    pq.push(起始状态);

    while (!pq.empty()) {
        State s = pq.top(); pq.pop();
        if (s.cost > dist[对应状态]) continue;   // 过期状态，跳过
        for (每种转移) {
            计算出新状态 ns 和花费 nc;
            if (nc < dist[ns]) {
                dist[ns] = nc;
                pq.push(ns);
            }
        }
    }
    // 对终点的所有相关状态取 min
}
```

### 4. 常见变体与技巧

- **分层图 / 拆点**：把状态维度（如"是否用过魔法""当前在哪一层"）直接当成图的节点编号，用一维 `dist[node]` 存，本质和本题的多维数组等价。
- **0-1 BFS**：边权只有 0 和 1 时，用 deque 代替优先队列（0 边插队首、1 边插队尾），复杂度从 `O(E log V)` 降到 `O(E)`。
- **二分答案 + Dijkstra**：形如"最小化路径上的最大边权 / 最小化第 k 大"的题，先二分答案，再用 Dijkstra 判定（如 P1462）。
- **正反两遍 Dijkstra**：求"源点到某点 + 该点回到源点"的最小和（如 P1629 邮递员送信）。
- **最短路计数**：在 Dijkstra 松弛时同步累加方案数（如 P1144）。
- **多源最短路**：对每个源各跑一遍 Dijkstra，或建超级源点（如 P1828）。

## 八、SPFA（BFS 风格）写法

洛谷上部分题解用"BFS"实现，严格说它们其实是 **SPFA（队列优化的 Bellman-Ford）**：代码结构和 BFS 一样（`while` + `queue`），但允许节点**反复入队、反复松弛**。

### 1. 为什么普通 BFS 不行

普通 BFS 按**步数**分层，每个格子**第一次访问就永久标记**。但本题边权是 0/1/2 不均匀，**步数少 ≠ 花费少**：

```text
起点(1,1)=红(0)，终点(3,1)=红(0)，中间 (2,1) 是无色格
路径1：2 步，用魔法跨过无色格 → 花费 2
路径2：绕远走一圈全是红色 0 的格子，5 步 → 花费 0
```

BFS 会先按步数走完"路径1"，把终点标成"已访问、花费 2"，从而**错过**更便宜的"路径2"。

### 2. SPFA 与 BFS 的关键区别

| | 普通 BFS | SPFA |
|---|---|---|
| 节点访问 | 第一次访问后**永久标记** | **允许反复入队**，找到更小花费就重新入队 |
| 依据 | 按"步数"分层 | 按"花费"反复松弛 |
| 标记数组 | `vis`（一次性） | `inq`（只表示"当前是否在队列"，出队后清除） |

### 3. SPFA 参考代码

```cpp
//
// 洛谷 P3956 棋盘 —— SPFA（BFS 风格）写法
// 思路：队列 + 反复松弛；节点只要被更新出更小花费就重新入队。
//

#include <iostream>
#include <queue>
#include <cstring>
using namespace std;

const int INF = 0x3f3f3f3f;
int m, n;
int grid[105][105];            // -1 无色，0 红，1 黄
int dist[105][105][2][2];      // 到某状态的最小花费
bool inq[105][105][2][2];      // 是否在队列中
int dx[4] = {-1, 1, 0, 0};
int dy[4] = {0, 0, -1, 1};

struct State { int x, y, color, used; };

void spfa() {
    memset(dist, 0x3f, sizeof(dist));
    queue<State> q;
    dist[1][1][grid[1][1]][0] = 0;
    q.push({1, 1, grid[1][1], 0});
    inq[1][1][grid[1][1]][0] = true;

    while (!q.empty()) {
        State s = q.front(); q.pop();
        inq[s.x][s.y][s.color][s.used] = false;   // 出队后清除，可再次入队
        int cur = dist[s.x][s.y][s.color][s.used]; // 用最新花费松弛

        for (int d = 0; d < 4; d++) {
            int nx = s.x + dx[d], ny = s.y + dy[d];
            if (nx < 1 || nx > m || ny < 1 || ny > m) continue;

            if (grid[nx][ny] != -1) {              // ① 真实有色格
                int c2 = grid[nx][ny];
                int nc = cur + (c2 == s.color ? 0 : 1);
                if (nc < dist[nx][ny][c2][0]) {
                    dist[nx][ny][c2][0] = nc;
                    if (!inq[nx][ny][c2][0]) {
                        q.push({nx, ny, c2, 0});
                        inq[nx][ny][c2][0] = true;
                    }
                }
            } else {                                // ② 无色格，用魔法
                if (s.used == 1) continue;
                int nc = cur + 2;
                if (nc < dist[nx][ny][s.color][1]) {
                    dist[nx][ny][s.color][1] = nc;
                    if (!inq[nx][ny][s.color][1]) {
                        q.push({nx, ny, s.color, 1});
                        inq[nx][ny][s.color][1] = true;
                    }
                }
            }
        }
    }
}

int main() {
    cin >> m >> n;
    memset(grid, -1, sizeof(grid));
    for (int i = 0; i < n; i++) {
        int x, y, c;
        cin >> x >> y >> c;
        grid[x][y] = c;
    }
    spfa();
    int ans = INF;
    for (int c = 0; c < 2; c++)
        for (int u = 0; u < 2; u++)
            ans = min(ans, dist[m][m][c][u]);
    cout << (ans == INF ? -1 : ans) << endl;
    return 0;
}
```

### 4. SPFA 与 Dijkstra 对比

| | SPFA（BFS 风格） | Dijkstra（优先队列） |
|---|---|---|
| 数据结构 | 普通 `queue` | `priority_queue`（小根堆） |
| 节点入队 | 可能多次（反复松弛） | 每个状态确定后只处理一次 |
| 正确性 | 非负权下正确 | 非负权下正确 |
| 复杂度 | 平均快，**最坏 O(VE)** 可能被卡 | 稳定 O(E log V) |

> 竞赛里更推荐 Dijkstra（更稳、不会被卡），但本题状态空间小，SPFA 也完全能过。
