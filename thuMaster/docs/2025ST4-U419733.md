# U419733 井字井字棋 题解

题目链接：<https://www.luogu.com.cn/problem/U419733>

## 一、题目大意

这是一道**井字井字棋（Ultimate Tic-Tac-Toe，终极井字棋）**的模拟题。

棋盘是 `3×3` 个大格，每个大格内又是一个 `3×3` 的小格（整体 `9×9`）。大格按行优先编号 `1..9`（第 `r` 行第 `c` 列为 `3(r-1)+c`，中心为 `5`），大格内小格同理编号。用 `(i,j)` 表示"编号为 `i` 的大格内编号为 `j` 的小格"。

规则：

1. 双方轮流落子（第 1 步先手，第 2 步后手，交替）。
2. **占领大格**：某个大格内，一方先在横/竖/斜方向连成三子，就占领这个大格。
3. **获胜**：整个棋盘上，一方先有 3 个"被自己占领的大格"连成一线（横/竖/斜），即获胜。
4. **落子限制**：
   - 不能下在已有棋子的格子里；
   - 大格被占领后，双方都不能再在该大格内落子；
   - 第一步不能下在 `(5,5)`（正中心）；
   - 若非第一步，设上一步对手下在 `(i,j)`：若编号为 `j` 的大格未被占领，则本步**必须下在编号为 `j` 的大格**；若已被占领，则可下在任意合法位置。
5. **平局判定**：若直到无处落子还未分出胜负，则先比"占领的大格数"，多者胜；若一样，再比"未占领的大格里落子的小格数"，多者胜（保证一定能分胜负）。

现给定一个棋谱（n 步落子，每步是 `(大格, 小格)`），判断：

- 是否**不合法**（输出 `illegal` 和第一个非法步编号）；
- 若合法，是否**分出胜负**（输出 `first`/`second` 和分出胜负的步编号）；
- 否则输出 `to be continued`。

## 二、解题思路：逐步模拟

只需按棋谱逐步模拟，每步做四件事：

1. **合法性检查**（按上文 4 条限制）；
2. **落子** `board[a][b] = 当前玩家`；
3. **更新大格占领**：检查大格 `a` 是否三连，若是则占领；
4. **判断胜负/满盘**：
   - 大格三连（整个棋盘）→ 分出胜负；
   - 棋盘已满（所有未占领大格里都没有空位）→ 平局判定。

核心是写一个 `win3` 函数判断 `3×3` 网格的三连（横、竖、两条对角线）。

关键细节：

- **大格编号 ↔ 小格编号的坐标换算**：编号 `s`（1..9）对应 `3×3` 的 `((s-1)/3, (s-1)%3)`；
- **落子跟随规则**：上一步的**小格编号** `j` 决定本步的**大格编号**（标准终极井字棋规则）；
- **平局判定**的统计：占领的大格数 = `cntBig[先手/后手]`；未占领大格里的落子数 = `cntSmall[先手/后手]`。

## 三、参考代码

```cpp
#include <iostream>
using namespace std;

int board[10][10];   // board[大格][小格]：0 空，1 先手，2 后手
int bigCap[10];      // 大格占领：0 未，1 先手，2 后手

// 3x3 三连判断
int win3(int g[3][3]) {
    for (int r=0;r<3;r++) if (g[r][0] && g[r][0]==g[r][1] && g[r][1]==g[r][2]) return g[r][0];
    for (int c=0;c<3;c++) if (g[0][c] && g[0][c]==g[1][c] && g[1][c]==g[2][c]) return g[0][c];
    if (g[0][0] && g[0][0]==g[1][1] && g[1][1]==g[2][2]) return g[0][0];
    if (g[0][2] && g[0][2]==g[1][1] && g[1][1]==g[2][0]) return g[0][2];
    return 0;
}

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n; cin >> n;
    int A[82], B[82];
    for (int k=1;k<=n;k++) cin >> A[k] >> B[k];

    for (int k=1;k<=n;k++) {
        int a=A[k], b=B[k];
        int p = (k%2==1) ? 1 : 2;

        // 合法性检查
        bool ill = false;
        if (board[a][b]!=0) ill = true;              // 已有棋子
        else if (bigCap[a]!=0) ill = true;           // 大格已占领
        else if (k==1 && a==5 && b==5) ill = true;   // 第一步不能下中心
        else if (k>1) {
            int pb = B[k-1];                          // 上一步的小格编号
            if (bigCap[pb]==0 && a!=pb) ill = true;   // 必须下在该大格
        }
        if (ill) { cout<<"illegal\n"<<k<<'\n'; return 0; }

        board[a][b] = p;

        // 大格 a 是否被占领
        int g[3][3];
        for (int s=1;s<=9;s++) g[(s-1)/3][(s-1)%3] = board[a][s];
        int bw = win3(g);
        if (bw) bigCap[a] = bw;

        // 整个棋盘是否获胜
        int gg[3][3];
        for (int i=1;i<=9;i++) gg[(i-1)/3][(i-1)%3] = bigCap[i];
        int ww = win3(gg);
        if (ww) { cout<<(ww==1?"first":"second")<<'\n'<<k<<'\n'; return 0; }

        // 棋盘是否已满
        bool full = true;
        for (int i=1;i<=9 && full;i++)
            if (bigCap[i]==0)
                for (int j=1;j<=9;j++)
                    if (board[i][j]==0){ full=false; break; }
        if (full) {
            int cntBig[3]={0,0,0}, cntSmall[3]={0,0,0};
            for (int i=1;i<=9;i++) cntBig[bigCap[i]]++;
            for (int i=1;i<=9;i++) if (bigCap[i]==0)
                for (int j=1;j<=9;j++) if (board[i][j]) cntSmall[board[i][j]]++;
            int w;
            if (cntBig[1]!=cntBig[2]) w = (cntBig[1]>cntBig[2])?1:2;
            else w = (cntSmall[1]>cntSmall[2])?1:2;
            cout<<(w==1?"first":"second")<<'\n'<<k<<'\n';
            return 0;
        }
    }
    cout<<"to be continued\n";
    return 0;
}
```

## 四、复杂度

- 每步：合法性检查 O(1)，落子 O(1)，大格三连检查 O(9)，整盘检查 O(9)，满盘检查 O(81)；
- 总复杂度 `O(81·n)`，`n ≤ 81`，完全够用。

## 五、常见错误

1. **落子跟随规则看错**：是"上一步的**小格编号**决定本步的大格"，不是上一步的大格编号；
2. **编号 ↔ 坐标换算错**：大格/小格都是 `((编号-1)/3, (编号-1)%3)` 的 `3×3` 坐标；
3. **漏掉"大格被占领后不能落子"**：合法性检查里 `bigCap[a] != 0` 这条不能忘；
4. **胜负与满盘的判断顺序**：先判"大格三连获胜"，再判"满盘平局"；
5. **平局统计口径**：第二个比较项是"**未占领**大格里的小格落子数"，不是全部小格；
6. **中心禁手**：只有**第一步**不能下 `(5,5)`，后续没有此限制。

## 六、小结

这是一道纯粹的**大模拟**题：把 Ultimate Tic-Tac-Toe 的规则逐条翻译成代码即可，没有算法难点，关键在于**规则理解的准确**（尤其是"落子跟随"和"平局判定"两条）。
