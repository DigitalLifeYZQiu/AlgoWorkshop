# U560763 Movie 题解

题目链接：<https://www.luogu.com.cn/problem/U560763>

## 一、题目大意

给定影片时长 `AB:CD:EF`（`AB` 时 `CD` 分 `EF` 秒）和帧率 `x`（帧/秒），求影片一共显示了多少帧。

```text
总帧数 = 总秒数 × x
总秒数 = 时 × 3600 + 分 × 60 + 秒
```

样例：

```text
2
00:00:01 1
06:06:06 120
```

- `00:00:01 1` → 1 秒 × 1 = `1` 帧；
- `06:06:06 120` → (6×3600 + 6×60 + 6) = 21966 秒 × 120 = `2635920` 帧。

数据范围：`1 ≤ T ≤ 100`，时 ≤ 99、分/秒 ≤ 59、`1 ≤ x ≤ 240`。最大值约 `8.6×10^7`，`int` 够用，建议 `long long` 保险。

## 二、解题思路

1. 读入 `时:分:秒` 和 `x`；
2. 换算成总秒数 `total = h*3600 + m*60 + s`；
3. 输出 `total * x`。

## 三、参考代码

```cpp
#include <cstdio>
using namespace std;

int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        int h, m, s, x;
        scanf("%d:%d:%d %d", &h, &m, &s, &x);      // 按格式读入
        long long total = (long long)h * 3600 + m * 60 + s;
        printf("%lld\n", total * x);
    }
    return 0;
}
```

## 四、几种字符串 / 时间读入写法

### 1. `scanf` 直接按格式读（推荐）

```cpp
int h, m, s, x;
scanf("%d:%d:%d %d", &h, &m, &s, &x);
```

格式串里的冒号是普通字符，要求输入里恰好是冒号；`%d` 自动跳过前导零和空白。

### 2. `cin` 直接按格式读（用 `char` 吞掉冒号）

```cpp
int h, m, s, x;
char colon;
cin >> h >> colon >> m >> colon >> s >> x;
```

`cin >> int` 读到非数字就停，`cin >> char` 正好读掉 `:`。

### 3. 读整串，用 `stringstream` + `getline` 分割

```cpp
#include <sstream>
string t; cin >> t;                 // "06:06:06"
stringstream ss(t);
string part;
vector<string> parts;
while (getline(ss, part, ':'))      // 以 ':' 为分隔符
    parts.push_back(part);
int h = stoi(parts[0]), m = stoi(parts[1]), s = stoi(parts[2]);
```

`stoi` 会自动去掉前导零。

### 4. 读整串，用 `find` + `substr` 分割

```cpp
string t; cin >> t;
int p1 = t.find(':');
int p2 = t.find(':', p1 + 1);
int h = stoi(t.substr(0, p1));
int m = stoi(t.substr(p1 + 1, p2 - p1 - 1));
int s = stoi(t.substr(p2 + 1));
```

### 5. `sscanf`（从字符串读，而非标准输入）

```cpp
char buf[20]; cin >> buf;
int h, m, s;
sscanf(buf, "%d:%d:%d", &h, &m, &s);
```

`sscanf` 与 `scanf` 用法相同，只是数据来源是字符串 `buf` 而不是标准输入。

## 五、`scanf` 用法详解

### 1. 基本语法与返回值

```c
int scanf(const char *format, ...);
```

- `format` 是格式串，由**格式说明符**（`%d` 等）和**普通字符**（如 `:`、空格）组成；
- 后面的可变参数是**变量的地址**（`&变量`）；
- **返回值**：成功读取并赋值的参数个数；读到输入末尾返回 `EOF`（通常是 `-1`）。

### 2. 常用格式说明符

| 说明符 | 含义 | 对应参数类型 |
|---|---|---|
| `%d` | 有符号十进制整数 | `int*` |
| `%lld` | 有符号长整数 | `long long*` |
| `%u` | 无符号十进制整数 | `unsigned int*` |
| `%c` | 单个字符 | `char*` |
| `%s` | 字符串（遇空白停止） | `char*` |
| `%f` | 单精度浮点 | `float*` |
| `%lf` | 双精度浮点 | `double*` |
| `%x` / `%o` | 十六进制 / 八进制 | `int*` |

### 3. 格式串里的普通字符要精确匹配

`scanf("%d:%d:%d", &h, &m, &s)` 要求输入里两个数之间**恰好是冒号**。若输入是 `6 6 6`（空格分隔）而格式串是 `%d:%d:%d`，则第二个 `%d` 匹配失败。

### 4. 空白与前导零

- 格式说明符 `%d`（及大多数说明符）会**自动跳过前导空白**（空格、换行、制表符）；
- `%d` 也**自动跳过前导零**：`"06"` 读成 `6`；
- 格式串里的**空白字符**（如空格）会匹配输入中任意数量的空白。

### 5. 常见坑

1. **忘记取地址符**：`scanf("%d", x)` 错，必须 `scanf("%d", &x)`；
2. **类型不匹配**：`%d` 配 `int`、`%lld` 配 `long long`，用错会读到错乱的值；
3. **`%s` 遇空白就停**，不能读带空格的整行（那要用 `gets` / `fgets` / `getline`）；
4. **`%c` 会读到残留的空白**：读数字后再 `%c` 常读到换行，可写 `" %c"`（前面加空格）来跳过；
5. **缓冲区残留**：`scanf` 不会清空多余输入，混用 `scanf` 和 `getline` 时要注意。

### 6. `scanf` vs `cin`

| | `scanf` | `cin` |
|---|---|---|
| 速度 | 更快（大量输入更明显） | 较慢，但可 `ios::sync_with_stdio(false)` 加速 |
| 格式控制 | 精确（如 `%d:%d:%d`） | 逐项 `>>`，需手动吞分隔符 |
| 类型安全 | 弱（靠格式串） | 强（自动推导） |
| 风格 | C 风格 | C++ 风格 |

竞赛里大量整数输入常用 `scanf`，或给 `cin` 关同步；两者都能通过本题。

## 六、复杂度与易错点

- 每组 O(1)，总 O(T)，瞬间完成；
- 易错点：忘记乘 3600/60、前导零处理（`%d` 已自动处理）、乘法溢出（用 `long long`）。
