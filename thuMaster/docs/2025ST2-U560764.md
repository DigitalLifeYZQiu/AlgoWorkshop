# U560764 Binary Matrix 题解

题目链接：<https://www.luogu.com.cn/problem/U560764>

## 一、题目大意

给定一个 `n × m` 的 0/1 矩阵 `A`。可以**翻转**若干格（0↔1），得到一个矩阵 `B`。要求 `B`：

- 每一行的异或和都为 0（每行 1 的个数为偶数）；
- 每一列的异或和都为 0（每列 1 的个数为偶数）。

求**最少翻转次数**（即 `A` 与 `B` 中不同的格子数）。

样例：

```text
2
3 3
010
101
010
3 3
000
000
000
```

输出：

```text
2
0
```

## 二、核心思路

### 1. 关键观察：翻转一格 = 同时翻转"行奇偶"和"列奇偶"

设 `r[i]` = 第 i 行的异或和（0 或 1），`c[j]` = 第 j 列的异或和。

翻转格子 `(i, j)` 会**同时翻转** `r[i]` 和 `c[j]`（两个都 0↔1），其它不变。

我们的目标是把所有 `r[i]`、`c[j]` 都变成 0。

### 2. 答案 = max(奇行数, 奇列数)

记：

```text
R = 异或和为 1 的行数（需要修正的行）
C = 异或和为 1 的列数（需要修正的列）
```

**答案 = `max(R, C)`**。

**下界**：每个"奇行"至少需要一次翻转（否则该行的异或和改不了），所以 ≥ R；同理 ≥ C。故 ≥ max(R, C)。

**上界**（构造，不妨设 R ≤ C，且 R 与 C 奇偶性相同）：

1. 把 R 个奇行与其中 R 个奇列两两配对，在交点各翻一次（共 R 次）——这 R 行、R 列都变成偶；
2. 剩下 `C - R` 个奇列（偶数个）两两配对，对每一对任选同一行翻两次（2 次不改该行奇偶，却让这两列各翻一次）——共 `C - R` 次。

总计 `R + (C - R) = C = max(R, C)` 次，达到下界。

> 注：R 与 C 的奇偶性必然相同，因为 `R mod 2 = 全矩阵 1 的个数 mod 2 = C mod 2`，所以 `C - R` 一定是偶数，配对可行。

## 三、参考代码

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        int n, m;
        cin >> n >> m;
        vector<string> a(n);
        for (int i = 0; i < n; i++) cin >> a[i];

        int R = 0;
        for (int i = 0; i < n; i++) {
            int x = 0;
            for (int j = 0; j < m; j++) x ^= (a[i][j] - '0');
            if (x) R++;
        }

        int C = 0;
        for (int j = 0; j < m; j++) {
            int x = 0;
            for (int i = 0; i < n; i++) x ^= (a[i][j] - '0');
            if (x) C++;
        }

        cout << max(R, C) << '\n';
    }
    return 0;
}
```

## 四、复杂度

- 统计行、列异或各需遍历矩阵一次，每组 `O(n·m)`；
- 总复杂度 `O(Σ n·m) ≤ O(10^6)`，`T` 组数据也瞬间完成。

## 五、常见错误

1. **用"1 的个数"而不用"异或和"**：两者模 2 等价，但异或更简洁；
2. **没意识到翻转同时影响行和列**：所以不是 `R + C`，而是 `max(R, C)`；
3. **字符转数字**：读入的是字符 `'0'/'1'`，要 `a[i][j] - '0'`；
4. **开数组大小**：`n, m ≤ 10^3` 且 `Σ n·m ≤ 10^6`，用 `vector<string>` 按需分配即可。

## 六、位运算操作与写法

本题用到了异或 `^` 来统计奇偶性，下面系统梳理常用位运算及写法。

### 1. 六种基本位运算符

| 运算符 | 名称 | 作用 | 示例（二进制） |
|---|---|---|---|
| `&` | 按位与 | 对应位都为 1 才为 1 | `5 & 3 = 1`（`101 & 011 = 001`） |
| `\|` | 按位或 | 对应位有 1 就为 1 | `5 \| 3 = 7`（`101 \| 011 = 111`） |
| `^` | 按位异或 | 对应位不同为 1，相同为 0 | `5 ^ 3 = 6`（`101 ^ 011 = 110`） |
| `~` | 按位取反 | 0↔1（按补码） | `~0 = -1`（全 1） |
| `<<` | 左移 | 每移一位相当于乘 2 | `1 << 3 = 8` |
| `>>` | 右移 | 每移一位相当于除 2（向下取整） | `8 >> 2 = 2` |

> 位运算只对**整数**有意义，且按二进制位逐位进行。

### 2. 复合赋值运算符

和 `+=` 一样，位运算也有复合形式：`x ^= y`（等价 `x = x ^ y`）、`x &= y`、`x |= y`、`x <<= k`、`x >>= k`。本题里 `x ^= (a[i][j] - '0')` 就是逐位异或累加。

### 3. 本题核心：异或 `^` 与奇偶性

异或的关键性质：

- 相同两数异或为 0：`a ^ a = 0`；
- 0 与任何数异或不变：`0 ^ a = a`；
- 交换律、结合律：`a ^ b ^ a = b`。

因此**一串 0/1 的异或和 = 其中 1 的个数 mod 2**，正是"奇偶性"。统计某行 1 的个数是否为偶数，写成：

```cpp
int x = 0;
for (int j = 0; j < m; j++) x ^= (a[i][j] - '0');   // x 最终为 0 或 1
```

比"逐个累加再取模"更简洁。

### 4. 常用技巧与写法

1. **判断奇偶**：`n & 1` 为 1 是奇数、为 0 是偶数（等价 `n % 2`）；
2. **交换两数（免临时变量）**：`a ^= b; b ^= a; a ^= b;`；
3. **取最低位的 1（lowbit）**：`x & -x`（树状数组 / 状压常用）；
4. **判断第 k 位是否为 1**：`(x >> k) & 1`；
5. **把第 k 位置为 1**：`x |= (1 << k)`；
6. **把第 k 位清为 0**：`x &= ~(1 << k)`；
7. **把第 k 位取反**：`x ^= (1 << k)`；
8. **去掉最低位的 1**：`x & (x - 1)`（统计 1 的个数、判断 2 的幂）；
9. **`1 << k` 表示 `2^k`**：如 `1 << 3 == 8`。

### 5. 口诀

- 判断奇偶用 `& 1`，翻转奇偶用 `^`；
- 置位用 `|`，清位用 `& ~`，取反用 `^`；
- 乘/除 2 的幂用 `<<` / `>>`（比乘除法快）。

## 七、小结

这题本质是一道**奇偶性 / 异或**的构造题：把"行列异或和为 0"翻译成"所有行列奇偶性为偶"，翻转一格等价于"同时取反一行一列"，于是答案就是 `max(奇行数, 奇列数)`。
