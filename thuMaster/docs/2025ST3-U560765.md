# U560765 Floor or Ceil 题解

题目链接：<https://www.luogu.com.cn/problem/U560765>

## 一、题目大意

对整数 `x`，有两种操作：

- 操作 1：`x ← ⌊x/2⌋`（下取整）；
- 操作 2：`x ← ⌈x/2⌉`（上取整）。

以**任意顺序**进行恰好 `n` 次操作 1 和 `m` 次操作 2，求这 `n+m` 次操作后 `x` 的最小值和最大值。

样例：

```text
4
12 1 2
12 1 1
12 0 0
12 1000000000 1000000000
```

输出：

```text
1 2
3 3
12 12
0 0
```

## 二、核心结论（已对拍验证）

```text
min = ⌊ ⌈x / 2^m⌉ / 2^n ⌋
max = ⌈ ⌊x / 2^n⌋ / 2^m ⌉
```

即：

- **最小值**：先把 `m` 次「上取整」做完（`x → ⌈x/2^m⌉`），再做 `n` 次「下取整」；
- **最大值**：先把 `n` 次「下取整」做完（`x → ⌊x/2^n⌋`），再做 `m` 次「上取整」。

## 三、为什么成立

两个关键事实：

1. **同类操作可合并**：
   - 连续 `m` 次上取整 = `⌈x / 2^m⌉`（因为 `⌈⌈x/a⌉/b⌉ = ⌈x/(ab)⌉`）；
   - 连续 `n` 次下取整 = `⌊x / 2^n⌋`。

2. **极端顺序就是"先一类后另一类"**：
   - 求**最小**：上取整在 `x` 还很大的时候做，"多出来的 +1"会被后续多次除以 2 稀释掉；而最后用下取整把可能的奇数结果"抹下去"。所以先全部上取整、再全部下取整。
   - 求**最大**：下取整在 `x` 很大的时候做，最后用上取整把奇数结果"抬上去"。所以先全部下取整、再全部上取整。

（该结论已用暴力枚举所有顺序，对拍 20 万组随机数据验证一致。）

## 四、参考代码

```cpp
#include <iostream>
using namespace std;

// floor(x / 2^c)，c 很大时结果为 0
long long floor_div2(long long x, long long c) {
    if (c >= 31) return 0;      // x < 2^30
    return x >> c;
}
// ceil(x / 2^c)
long long ceil_div2(long long x, long long c) {
    if (x == 0) return 0;
    if (c >= 31) return 1;      // 0 < x < 2^30 <= 2^c
    return (x + ((1LL << c) - 1)) >> c;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        long long x, n, m;
        cin >> x >> n >> m;
        long long mn = floor_div2(ceil_div2(x, m), n);
        long long mx = ceil_div2(floor_div2(x, n), m);
        cout << mn << ' ' << mx << '\n';
    }
    return 0;
}
```

## 五、复杂度

每组 `O(1)`，总 `O(T)`；`T ≤ 2×10^5` 瞬间完成。

## 六、常见错误

1. **直接模拟 `n+m` 次操作**：`n,m` 可达 `10^9`，会超时，要用公式；
2. **`2^n` 溢出**：`n,m` 很大时 `1LL << n` 会溢出，要对 `c` 做封顶（`x < 2^30`，`c ≥ 31` 时 `⌊x/2^c⌋=0`、`⌈x/2^c⌉=1`（x>0））；
3. **上取整写法**：`ceil(x/2) = (x+1)/2`（整数），不要用浮点 `ceil`；
4. **顺序搞反**：最小是"先 ceil 后 floor"，最大是"先 floor 后 ceil"，别写反。

## 七、小结

这题的关键是**同类取整操作可合并**，以及**求极值时"先上取整/先下取整"的极端顺序**。最终化成两个 `O(1)` 的表达式。
