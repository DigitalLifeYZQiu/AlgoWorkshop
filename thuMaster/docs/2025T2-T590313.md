# T590313 Bloxorz 题解

题目链接：<https://www.luogu.com.cn/problem/T590313>

## 一、题目大意

Bloxorz 是一款益智游戏。棋盘是 `n × m` 网格，每格为：

- `#`：空地（方块不能放上去）；
- `.`：地面；
- `E`：玻璃；
- `X`：初始位置（恰好一个 `X`，或相邻的两个 `X`）；
- `O`：目标位置（恰好一个）。

方块是 `1×1×2` 的长方体：

- 可以**竖放**在**一格地面**上（`.`，含 `X`/`O`，但**不能**在玻璃 `E` 上）；
- 可以**平放**在**相邻的两格**上（这两格可以是地面或玻璃，即只要不是 `#`）。

每次操作把方块向某方向**滚动 90°**。求把方块**竖放**到 `O` 上的**最少操作数**，达不到输出 `-1`。

多组数据：`1 <= T <= 5`，`3 <= n, m <= 500`。

## 二、解题思路

### 1. 核心：方块有 3 种姿态

方块滚动时在「竖放、横躺、竖躺」之间切换，所以 BFS 状态是三维的 `(x, y, lie)`：

| `lie` | 含义 | 占据的格子 |
|---|---|---|
| `0` | 竖放（站立） | `(x, y)` |
| `1` | 平放·横向 | `(x, y)` 和 `(x, y+1)`（`(x,y)` 是左格） |
| `2` | 平放·纵向 | `(x, y)` 和 `(x+1, y)`（`(x,y)` 是上格） |

### 2. 滚动转移表

12 种转移（3 姿态 × 4 方向），用查表 `nxt[lie][dir] = {dx, dy, 新lie}`：

```cpp
// 方向: 0上 1下 2左 3右
int nxt[3][4][3] = {
    {{-2, 0, 2}, {1, 0, 2}, {0, -2, 1}, {0, 1, 1}},  // lie=0 站立
    {{-1, 0, 1}, {1, 0, 1}, {0, -1, 0}, {0, 2, 0}},  // lie=1 横躺
    {{-1, 0, 0}, {2, 0, 0}, {0, -1, 2}, {0, 1, 2}},  // lie=2 竖躺
};
```

例如站立 `(x,y)` 向上滚 → 变纵向平躺，占据 `(x-2,y)` 和 `(x-1,y)`，新状态 `(x-2, y, 2)`。

### 3. 合法性判断

滚动后的姿态必须能"放得住"：

```cpp
bool valid(int x, int y, int lie) {
    if (越界) return false;
    if (lie == 0) return g[x][y] != '#' && g[x][y] != 'E';   // 站立：只能在地面
    if (lie == 1) return g[x][y] != '#' && g[x][y+1] != '#'; // 横躺：两格都不是 #
    /* lie == 2 */ return g[x][y] != '#' && g[x+1][y] != '#'; // 竖躺：两格都不是 #
}
```

> 关键区别：**站立不能落在玻璃 `E` 上**（会碎），但平放可以压在玻璃上。

### 4. BFS

从初始状态出发，每次尝试 4 个方向，合法且未访问就入队；**第一次遇到 `lie==0` 且 `g[x][y]=='O'` 时返回步数**（BFS 保证最少）。

## 三、参考代码

```cpp
//
// 洛谷 T590313 Bloxorz
// 思路：状态 (x, y, lie) 三维 BFS，查表滚动，求最少步数。
//

#include <iostream>
#include <queue>
#include <cstring>
using namespace std;

int n, m;
char g[505][505];
int dist[3][505][505];

int nxt[3][4][3] = {
    {{-2, 0, 2}, {1, 0, 2}, {0, -2, 1}, {0, 1, 1}},
    {{-1, 0, 1}, {1, 0, 1}, {0, -1, 0}, {0, 2, 0}},
    {{-1, 0, 0}, {2, 0, 0}, {0, -1, 2}, {0, 1, 2}},
};

struct State { int x, y, lie; };

bool valid(int x, int y, int lie) {
    if (x < 0 || x >= n || y < 0 || y >= m) return false;
    if (lie == 0) return g[x][y] != '#' && g[x][y] != 'E';
    if (lie == 1) return y + 1 < m && g[x][y] != '#' && g[x][y+1] != '#';
    return x + 1 < n && g[x][y] != '#' && g[x+1][y] != '#';
}

int bfs(int sx, int sy, int slie) {
    memset(dist, -1, sizeof(dist));
    queue<State> q;
    q.push({sx, sy, slie});
    dist[slie][sx][sy] = 0;
    while (!q.empty()) {
        State s = q.front(); q.pop();
        int x = s.x, y = s.y, lie = s.lie;
        if (lie == 0 && g[x][y] == 'O') return dist[lie][x][y];
        for (int d = 0; d < 4; d++) {
            int nx = x + nxt[lie][d][0];
            int ny = y + nxt[lie][d][1];
            int nlie = nxt[lie][d][2];
            if (!valid(nx, ny, nlie)) continue;
            if (dist[nlie][nx][ny] != -1) continue;
            dist[nlie][nx][ny] = dist[lie][x][y] + 1;
            q.push({nx, ny, nlie});
        }
    }
    return -1;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T; cin >> T;
    while (T--) {
        cin >> n >> m;
        int x1 = -1, y1 = -1, x2 = -1, y2 = -1;
        for (int i = 0; i < n; i++) {
            cin >> g[i];
            for (int j = 0; j < m; j++)
                if (g[i][j] == 'X') {
                    if (x1 == -1) { x1 = i; y1 = j; }
                    else { x2 = i; y2 = j; }
                }
        }
        int sx, sy, slie;
        if (x2 == -1) { sx = x1; sy = y1; slie = 0; }
        else if (x1 == x2) { sx = x1; sy = min(y1, y2); slie = 1; }
        else { sx = min(x1, x2); sy = y1; slie = 2; }
        cout << bfs(sx, sy, slie) << '\n';
    }
    return 0;
}
```

## 四、复杂度

- 状态数：`3 × n × m ≈ 3 × 500 × 500 = 75 万`；
- BFS：每个状态 4 次转移，`O(3nm)`，`T <= 5` 组也轻松在 1 秒内完成；
- 空间：`dist[3][505][505] ≈ 3 MB`。

## 五、常见错误

1. **姿态没建模**：只记 `(x,y)` 会丢信息，同样位置在不同姿态下转移完全不同。
2. **站立不能落在玻璃上**：`E` 只能被"平放"压，不能被"站立"压，漏了会多算。
3. **转移表写错**：站立滚动一次位移 2 格、平放滚成站立位移 1~2 格，`nxt` 表要仔细核对。
4. **两个 X 的初始姿态**：同行是横躺、同列是竖躺，`(x,y)` 要取左/上格。
5. **没判越界**：虽然题目保证四周是 `#`，但滚动后可能出界，仍需显式判范围。

## 六、小结

| 要点 | 说明 |
|---|---|
| 状态 | `(x, y, lie)`，三维 |
| 转移 | 查表 `nxt[3][4][3]`（12 种） |
| 合法性 | 站立限地面、平放限非 `#` |
| 目标 | 站立在 `O` 上 |

核心一句话：**方块有体积和姿态，就把"姿态"编码进搜索状态，再用 BFS 求最少步数。**
