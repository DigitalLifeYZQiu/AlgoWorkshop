# T590312 见 题解

题目链接：<https://www.luogu.com.cn/problem/T590312>

## 一、题目大意

一个 `n × n` 网格（`n <= 100`），`h[i][j]` 是柱子的高度（`1 <= h[i][j] <= n`）。

从四个方向看，求能看到的柱子数量：

- `l_i`：从第 i 行**左侧**向右看；
- `r_i`：从第 i 行**右侧**向左看；
- `u_i`：从第 i 列**上侧**向下看；
- `d_i`：从第 i 列**下侧**向上看。

规则：

> 一根**更远**的柱子，如果高度**不超过**某根**更近**的柱子，就看不到。

换句话说：**一根柱子能被看到，当且仅当它严格高于它前面（该方向）的所有柱子。**

样例1：

```text
输入：                    输出：
4                        2 3 2 2
3 4 2 1                  2 2 1 3
2 1 4 3                  1 3 2 2
4 3 1 2                  4 1 3 1
1 2 3 4
```

第 1 行 `3 4 2 1`：

- 从左看：`3` 可见，`4` 比 `3` 高可见，`2`、`1` 被 `4` 挡住 → `l_1 = 2`；
- 从右看：`1` 可见，`2` 可见，`4` 可见，`3` 被 `4` 挡住 → `r_1 = 3`。

## 二、解题思路

能被看到的柱子，就是**"不断打破历史最高纪录"**的那些柱子：

- 从左看第 i 行：维护当前最大值 `mx`，遇到 `h[i][j] > mx` 就 `l_i++` 并更新 `mx`；
- 其余三个方向同理，只是遍历顺序不同。

这正是"严格前缀最大值的记录数"。

## 三、参考代码

```cpp
//
// 洛谷 T590312 见
// 思路：可见 <=> 严格前缀最大值；四个方向各扫一遍。
//

#include <iostream>
using namespace std;

int n;
int h[105][105];
int l[105], r[105], u[105], d[105];

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            cin >> h[i][j];

    // 每行的 l（左→右）和 r（右→左）
    for (int i = 1; i <= n; i++) {
        int mx = 0;
        for (int j = 1; j <= n; j++)
            if (h[i][j] > mx) { l[i]++; mx = h[i][j]; }
        mx = 0;
        for (int j = n; j >= 1; j--)
            if (h[i][j] > mx) { r[i]++; mx = h[i][j]; }
    }

    // 每列的 u（上→下）和 d（下→上）
    for (int j = 1; j <= n; j++) {
        int mx = 0;
        for (int i = 1; i <= n; i++)
            if (h[i][j] > mx) { u[j]++; mx = h[i][j]; }
        mx = 0;
        for (int i = n; i >= 1; i--)
            if (h[i][j] > mx) { d[j]++; mx = h[i][j]; }
    }

    for (int i = 1; i <= n; i++)
        cout << l[i] << ' ' << r[i] << ' ' << u[i] << ' ' << d[i] << '\n';
    return 0;
}
```

## 四、复杂度

- 四个方向各扫一遍矩阵，`O(n²)`；
- `n <= 100`，瞬间完成；空间 `O(n²)`。

## 五、易错点

1. **必须"严格大于"才可见**：等于不算（"不超过"即 `<=` 会被挡住），判断是 `h > mx` 而不是 `h >= mx`。
2. **`mx` 初始值**：高度 `>= 1`，初始 `mx = 0`（或负无穷）即可保证最靠近的一根一定可见。
3. **方向别搞混**：`l_i / r_i` 对应**行**（横向扫描），`u_i / d_i` 对应**列**（纵向扫描），输出顺序是 `l r u d`。

## 六、小结

把"可见"翻译成"严格前缀最大值"，四个方向各来一遍前缀/后缀扫描即可，无需任何搜索或数据结构。
